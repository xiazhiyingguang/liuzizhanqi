# 六子战棋 · 专属武器图片

已制作当前游戏图鉴中的全部 43 位可用角色的专属武器，采用统一国风奇幻道具插画风格。

- 最终素材均为 1254 × 1254 的透明背景 PNG。
- 用浏览器打开 `index.html` 可查看、搜索、筛选、放大和下载。
- `manifest.json` 记录角色 ID、角色名、武器名、职业和最终图片路径。
- `generation-prompts.json` 保存完整生成提示词；`refinement-prompts.json` 保存修整提示词。
- 图片使用内置 `image_gen` 生成。
- 杰茨米、云缨和血契采用 `jetzmi-v2.png`、`yunying-v2.png`、`xueqi-v2.png` 修整版；血契「赤枷」为红色长柄镰刀。目录里的同名初版为备用草稿，完整素材包只包含最终版。
- 本画集覆盖当前可用角色；下架角色与尚未加入游戏的角色不包含在本批次。
