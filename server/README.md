# 六子战棋局域网服务器

推荐从项目根目录启动：

```bash
npm run lan
```

该命令会构建前端，并由本服务器在 `0.0.0.0:8787` 同时提供网页、HTTP 状态接口和 Socket.IO 实时通信。局域网中的玩家打开终端打印出的同一个网址即可。

玩家无需填写名称。服务器支持双方输入相同四位数字自动配对，也支持在线状态、最近对手识别和直接邀请。浏览器生成的玩家身份与最近对战记录保存在本机站点数据中。

单独启动服务器：

```bash
npm start
```

可用环境变量：

- `PORT`：监听端口，默认 `8787`
- `HOST`：监听地址，默认 `0.0.0.0`

状态接口：

- `GET /api/health`：服务器状态与活跃房间数
- `GET /api/rooms`：活跃房间摘要（调试用）

房间数据仅保存在内存中。任一玩家离开或断线时房间关闭；超过一小时没有操作的房间会自动清理。
